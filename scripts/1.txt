8. Recommended current workflow
-------------------------------

Step B: Prepare Hugging Face L2Arctic subset

python -m src.data.prepare_external_datasets --datasets common_accent common_native english_dialects --max-per-label 80 --max-total-per-config 120 --max-scan 3000 --eval

python -m src.exp0_run_baseline --source hf --hf-split scripted --samples 300 --seed 42 --output results\logs\exp0_hf_300.csv
python -m src.exp0_run_baseline --source external --samples 300 --seed 42 --output results\logs\exp0_external_300.csv

Step E: Make file-level and speaker-disjoint splits

python -m src.data.make_splits

Step F: Later train two models

Exp1: DistilHuBERT on train_file_level.csv, validate on val_file_level.csv
Exp2: DistilHuBERT on train_speaker_disjoint.csv, validate on val_speaker_disjoint.csv


9. Important notes
------------------

Use python -m after refactoring.

Correct:

python -m src.data.prepare_l2arctic
python -m src.data.prepare_l2arctic_official
python -m src.data.prepare_external_datasets
python -m src.exp0_run_baseline --source official --samples 10

Avoid direct script execution after refactoring:

python src\data\prepare_l2arctic.py
python src\data\prepare_l2arctic_official.py
python src\data\prepare_external_datasets.py
python src\exp0_run_baseline.py

Reason:

After refactoring, scripts import modules like src.utils.constants.
Running with python -m keeps the project root on Python's module search path.
